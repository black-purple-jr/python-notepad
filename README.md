### To create your own virtual environement:

```bash
python -m venv .venv
```
<hr>

### To activate that virtual environement:

on Windows
```bash
./.venv/scripts/activate
```

on Linux / MacOS
```bash
./.venv/bin/activate
```
<hr>

### Get the necessary package:

```bash
pip install PySide6
```
